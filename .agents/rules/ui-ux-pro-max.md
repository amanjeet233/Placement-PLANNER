# Project & Workspace Guidelines: UI/UX Pro Max Workflow

Whenever designing, developing, editing, or reviewing interfaces (HTML, CSS, JavaScript, React, Tailwind, dashboards, placement plans, web pages, or components):

## 1. UI/UX Pro Max Principles
- Treat UI/UX as a primary design deliverable, not an afterthought.
- Follow the rules, style references, and palettes from the `ui-ux-pro-max` skill.
- Craft interfaces that look modern, vibrant, and production-ready.

## 2. Visual Style & Tokens
- **Color Palette**: Use the 60-30-10 principle (60% background/canvas, 30% card/surface structure, 10% high-contrast brand accent).
- **Typography**: Use modern Google fonts (e.g., *Outfit*, *Inter*, *Plus Jakarta Sans*, *Poppins*) with well-defined weights and line heights.
- **Hierarchy & Contrast**: Ensure all text passes WCAG AA contrast standards (>= 4.5:1).
- **Spacing**: Follow consistent 4px/8px modular scale.

## 3. Micro-Interactions & Polish
- Subtle animations, hover states, active transitions, and smooth transforms for buttons and cards.
- Clean rounded corners (`border-radius: 8px` to `16px`), glassmorphic backdrop filters where appropriate, and soft shadows.
- Fully responsive layouts supporting mobile, tablet, and wide desktop screens.
